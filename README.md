Forecasts each Grand Theft Auto VI PlayStation 5 trophy's earn rate on Exophase at the case's target, from the history of reads in each case. It forecasts earners and the tracked population separately, because the population grows faster than any trophy's earners early on and dilutes the rates, then combines them into five quantiles per trophy on the logit scale.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
